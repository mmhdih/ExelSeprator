# 📊 Excel Separator | مقسم هوشمند فایل‌های اکسل 🚀

یک نرم‌افزار قدرتمند و زیبا با رابط کاربری مدرن برای جداسازی و مدیریت سریع فایل‌های حجیم اکسل. این برنامه به شما کمک می‌کند تا داده‌های خود را در کمترین زمان ممکن پردازش و تفکیک کنید.

## ✨ ویژگی‌های کلیدی

- **🎨 رابط کاربری زیبا و مدرن:** طراحی شده با بهترین استانداردهای UI برای تجربه کاربری لذت‌بخش.
- **⚡ سرعت بالا:** پردازش فایل‌های سنگین اکسل در کسری از ثانیه.
- **⚙️ تفکیک دقیق داده‌ها:** امکان جداسازی بر اساس شیت‌ها، ستون‌ها یا ردیف‌های خاص.
- **🖥️ نسخه مستقل ویندوز:** بدون نیاز به نصب پایتون، فقط با یک کلیک اجرا کنید!

## 🛠️ تکنولوژی‌های استفاده شده

- **فرانت‌اند (رابط کاربری):** CustomTkinter
- **بک‌اند (پردازش داده):** Python & Pandas
- **بیلد خودکار:** GitHub Actions & PyInstaller
