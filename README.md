## این برنامه چه کاری انجام می‌دهد؟

فرض کنید یک فایل اکسل با ده‌هزار سطر فروش دارید و ستونی به نام «شهر» در آن هست.
با این برنامه، فایل ورودی را می‌دهید، ستون «شهر» را انتخاب می‌کنید، و برنامه به ازای
هر شهر یک فایل اکسل جداگانه می‌سازد؛ هر فایل فقط سطرهای همان شهر را دارد و عنوان
ستون‌ها هم سر جای خودش باقی می‌ماند.

| فایل ورودی | فایل‌های خروجی |
| --- | --- |
| `فروش.xlsx` (۱۰٬۰۰۰ سطر) | `تهران.xlsx`، `شیراز.xlsx`، `اصفهان.xlsx`، … |

همین. بدون فرمول، بدون ماکرو، بدون کپی‌وپیست دستی.

## امکانات

### پردازش

- **قالب‌های ورودی:** `xlsx`، `xlsm`، `xls` و `csv`
- **انتخاب شیت:** اگر فایل چند شیت داشته باشد، هرکدام را می‌توانید انتخاب کنید
- **تعیین سطر عنوان‌ها:** اگر جدول شما از سطر اول شروع نمی‌شود (مثلاً چند سطر تیتر
  و توضیح بالای جدول دارید)، شماره سطر عنوان را مشخص کنید
- **دو حالت خروجی:** چند فایل جدا، یا یک فایل اکسل که هر گروه در یک شیت آن است
- **دو قالب خروجی:** `xlsx` یا `csv` (با کدگذاری `utf-8-sig` که در اکسل درست باز می‌شود)
- **مدیریت سطرهای خالی:** سطرهایی که در ستون انتخابی مقدار ندارند می‌توانند در یک
  گروه جداگانه ذخیره شوند یا کنار گذاشته شوند
- **نام‌گذاری امن:** کاراکترهای غیرمجاز ویندوز، نام‌های رزرو شده و نام‌های تکراری
  همگی مدیریت می‌شوند تا هیچ فایلی روی فایل دیگر نوشته نشود

### رابط کاربری

- **کاملاً راست‌چین و فارسی** — از چیدمان اجزا تا شکل‌گیری درست حروف
- **طراحی مینیمال** با قلم [وزیرمتن](https://github.com/rastikerdar/vazirmatn) که
  همراه خود برنامه بسته‌بندی شده و نیازی به نصب جداگانه ندارد
- **تم روشن و تیره** با یک کلید تعویض؛ به‌صورت پیش‌فرض از تنظیمات سیستم پیروی می‌کند
- **بدون قفل شدن پنجره:** پردازش در نخ جداگانه انجام می‌شود، نوار پیشرفت را می‌بینید
  و هر لحظه می‌توانید عملیات را لغو کنید
- **پیش‌بینی نتیجه:** پیش از اجرا به شما می‌گوید دقیقاً چند فایل ساخته می‌شود
- **بدون پنجره‌های هشدار مزاحم:** خطاها و راهنمایی‌ها در همان نوار وضعیت پایین صفحه
  نمایش داده می‌شوند

## نصب و اجرا

### راه اول: نسخه پرتابل ویندوز (پیشنهاد می‌شود)

۱. به صفحه [Releases](https://github.com/mmhdih/ExelSeprator/releases/latest) بروید
۲. فایل `ExcelSeparator-vX.Y.Z-portable-x64.exe` را دانلود کنید
۳. روی آن دوبار کلیک کنید

همین. نه نصب لازم است، نه پایتون، نه هیچ پیش‌نیاز دیگری. فایل را می‌توانید روی
فلش بگذارید و روی هر ویندوزی اجرا کنید.

> [!NOTE]
> اگر خواستید صحت فایل دانلودشده را بررسی کنید، فایل `.sha256` کنار آن را
> دانلود کرده و در PowerShell اجرا کنید:
> ```powershell
> Get-FileHash .\ExcelSeparator-vX.Y.Z-portable-x64.exe -Algorithm SHA256
> ```

### راه دوم: اجرا از سورس کد

نیازمند **پایتون ۳٫۱۰ یا بالاتر** (روی ۳٫۱۱ و ۳٫۱۲ آزمایش شده است).

```bash
git clone https://github.com/mmhdih/ExelSeprator.git
cd ExelSeprator

python -m venv .venv
source .venv/bin/activate        # در ویندوز: .venv\Scripts\activate

pip install -r requirements.txt
python main.py
```

> [!IMPORTANT]
> در لینوکس اگر با خطای `No module named 'tkinter'` روبه‌رو شدید، بسته سیستمی آن
> را نصب کنید:
> ```bash
> sudo apt install python3-tk      # دبیان و اوبونتو
> sudo dnf install python3-tkinter # فدورا
> ```

## راهنمای استفاده گام‌به‌گام

### گام ۱ — فایل‌ها

| کنترل | توضیح |
| --- | --- |
| **فایل ورودی** | فایل اکسل یا CSV خود را انتخاب کنید |
| **شیت** | اگر فایل چند شیت دارد، شیت مورد نظر را انتخاب کنید |
| **سطر عنوان‌ها** | شماره سطری که نام ستون‌ها در آن است (پیش‌فرض: ۱) |
| **پوشه خروجی** | جایی که فایل‌های ساخته‌شده در آن ذخیره می‌شوند |

پس از انتخاب فایل، برنامه به‌طور خودکار یک پوشه خروجی کنار فایل ورودی پیشنهاد
می‌دهد که در صورت نیاز می‌توانید عوضش کنید.

### گام ۲ — نحوه جداسازی

| کنترل | توضیح |
| --- | --- |
| **ستون** | ستونی که مبنای جداسازی است. کنار نام هر ستون تعداد گروه‌های آن نوشته شده |
| **خروجی** | چند فایل جدا، یا یک فایل چندشیتی |
| **قالب** | اکسل (`xlsx`) یا `csv` |
| **سطرهای بدون مقدار** | سطرهای فاقد مقدار در ستون انتخابی، در گروه «بدون مقدار» ذخیره شوند یا نه |

نوار پایین صفحه همیشه به شما می‌گوید نتیجه چه خواهد بود؛ مثلاً:
«۳۲۰ سطر و ۳ ستون خوانده شد — ۶ فایل xlsx ساخته می‌شود».

### گام ۳ — اجرا

دکمه **شروع جداسازی** تا وقتی همه ورودی‌های لازم آماده نشده باشند غیرفعال است.
پس از شروع، همان دکمه به **لغو عملیات** تبدیل می‌شود و در پایان کار، دکمه
**باز کردن پوشه خروجی** ظاهر می‌شود.

## حالت‌های خروجی

### چند فایل جدا

به ازای هر مقدار یکتای ستون، یک فایل ساخته می‌شود:

```
خروجی/
├── تهران.xlsx
├── شیراز.xlsx
├── اصفهان.xlsx
└── بدون مقدار.xlsx
```

مناسب وقتی که می‌خواهید هر بخش را جداگانه برای کسی بفرستید.

### یک فایل چندشیتی

همه گروه‌ها در یک فایل اکسل و هرکدام در یک شیت جدا:

```
خروجی/
└── فروش-تفکیک‌شده.xlsx
    ├── شیت «تهران»
    ├── شیت «شیراز»
    └── شیت «اصفهان»
```

مناسب وقتی که می‌خواهید همه‌چیز در یک فایل بماند. سقف این حالت **۲۰۰ شیت** است؛
اگر تعداد گروه‌ها بیشتر باشد برنامه پیش از شروع به شما اطلاع می‌دهد.

## نام‌گذاری فایل‌های خروجی

مقادیر داخل سلول‌های اکسل معمولاً برای تبدیل مستقیم به نام فایل مناسب نیستند.
برنامه این موارد را خودکار مدیریت می‌کند:

| مشکل | مثال ورودی | نام خروجی |
| --- | --- | --- |
| کاراکتر غیرمجاز ویندوز | `تهران/کرج` | `تهران-کرج.xlsx` |
| چند کاراکتر غیرمجاز پشت سر هم | `a<>:?b` | `a-b.xlsx` |
| نام رزرو شده ویندوز | `CON` | `CON-1.xlsx` |
| فاصله یا نقطه اضافه | `‌  تهران  ` | `تهران.xlsx` |
| نام‌های تکراری پس از پاک‌سازی | `a/b` و `a:b` | `a-b.xlsx` و `a-b-2.xlsx` |
| نام خیلی طولانی | ۵۰۰ کاراکتر | کوتاه‌شده به ۱۲۰ کاراکتر |
| مقدار خالی | (سلول خالی) | `بدون مقدار.xlsx` |

در حالت چندشیتی هم نام شیت‌ها به سقف ۳۱ کاراکتر اکسل و کاراکترهای مجاز آن محدود
می‌شود.

```
ExelSeprator/
├── main.py                      نقطه شروع برنامه

├── frontend/                    رابط کاربری

│   ├── components.py            اجزای پایه (کارت، دکمه، منوی کشویی، …)
│   ├── theme.py                 زبان طراحی: رنگ، فاصله، قلم
│   └── rtl.py                   شکل‌دهی متن فارسی و ابزارهای راست‌چین
│
├── assets/
│   ├── icon.ico / icon.png      آیکون برنامه
│   └── fonts/                   قلم وزیرمتن (مجوز OFL)
│
├── packaging/
│   └── make_version_info.py     ساخت اطلاعات نسخه برای فایل exe

نمایش و تعامل را انجام می‌دهد.

## استفاده از موتور پردازش در کد خودتان

```python
from backend.excel_processor import ExcelProcessor

processor = ExcelProcessor()

# فهرست شیت‌های فایل
print(ExcelProcessor.list_sheets("فروش.xlsx"))

# بارگذاری و دیدن وضعیت ستون‌ها
for column in processor.load("فروش.xlsx", sheet_name="فروردین", header_row=1):
    print(column.name, column.unique_count, column.blank_count)

# جداسازی
result = processor.split(
    "شهر",
    "خروجی",
    output_format="xlsx",       # یا "csv"
    single_workbook=False,      # True یعنی یک فایل چندشیتی
    include_blanks=True,
    progress=lambda done, total, label: print(f"{done}/{total} — {label}"),
)

print(result.file_count, "فایل از", result.row_count, "سطر ساخته شد")
```

برای لغو عملیات از `threading.Event` استفاده کنید:

```python
import threading

cancel = threading.Event()
# از یک نخ دیگر: cancel.set()

processor.split("شهر", "خروجی", cancel_event=cancel)   # OperationCancelled
```

خطاهای قابل نمایش به کاربر از نوع `ProcessingError` هستند و متن فارسی دارند.

## ساخت نسخه پرتابل

### به‌صورت خودکار (GitHub Actions)

با **هر کامیت روی هر شاخه** یک نسخه پرتابل ساخته می‌شود و در بخش
[Actions](https://github.com/mmhdih/ExelSeprator/actions) به‌عنوان Artifact قابل
دانلود است. جریان کار سه مرحله دارد:

| مرحله | سیستم‌عامل | کار |
| --- | --- | --- |
| `test` | Ubuntu | اجرای تست‌های موتور پردازش |
| `build` | Windows | ساخت فایل exe تک‌تکه و محاسبه SHA256 |
| `release` | Ubuntu | روی تگ `vX.Y.Z` یا اجرای دستی: انتشار Release با فایل ضمیمه |

### به‌صورت دستی (روی ویندوز)

```bash
pip install -r requirements-dev.txt
python packaging/make_version_info.py
pyinstaller --noconfirm --clean ExcelSeparator.spec
```

خروجی در `dist/ExcelSeparator.exe` ساخته می‌شود؛ یک فایل مستقل که قلم، آیکون و
تمام وابستگی‌ها داخل خودش بسته‌بندی شده است.

### انتشار نسخه جدید

۱. شماره نسخه را در `app_meta.py` تغییر دهید
۲. تغییر را کامیت کنید
۳. یکی از این دو راه را برای انتشار انتخاب کنید:

**با تگ:**

```bash
git tag v2.1.0
git push origin v2.1.0
```

**یا از رابط گیت‌هاب:** در بخش Actions روی جریان کار
«ساخت نسخه پرتابل ویندوز» → **Run workflow** → گزینه
`publish_release` را تیک بزنید. تگ به‌طور خودکار روی همان کامیت ساخته می‌شود.

در هر دو حالت، فایل exe ساخته و به Release ضمیمه می‌شود.

```bash
EXCELSEP_DISABLE_RESHAPE=1 python main.py
